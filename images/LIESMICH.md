# Fotos

Pro Auto fünf Bilder im JPG-Format, benannt nach diesem Muster:

- `<id>-front.jpg`
- `<id>-side.jpg`
- `<id>-rear.jpg`
- `<id>-interior-1.jpg`
- `<id>-interior-2.jpg`

IDs: polestar, zeekr, zeekr7gt, volvo, xpengg9, xpeng, tesla, enyaq, elroq, idtiguan, idcross, leapmotor, smart5, q4

Beispiel: `polestar-front.jpg`. Nur Bilder verwenden, für die eine Nutzungserlaubnis besteht.
